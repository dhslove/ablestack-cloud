기본 스토리지 선택 · 예외 상태

목록 영역 안에서 상태를 설명하고, 업데이트와 생성 버튼은 기존 상단·요약 영역을 사용합니다.

1. 호환되는 스토리지 없음

루트 디스크의 기본 스토리지
▱
선택한 오퍼링과 배포 조건에 맞는 기본 스토리지가 없습니다.
오퍼링 또는 배포 인프라를 변경하세요.
직접 선택·자동 선택 모두 생성 조건을 만족하지 못하면 VM 시작 비활성화

2. 목록 또는 용량 조회 실패

데이터 디스크의 기본 스토리지
스토리지 정보를 가져올 수 없습니다.상단 업데이트를 눌러 다시 시도하세요. 확인 전에는 선택한 스토리지로 생성할 수 없습니다.
이전에 조회한 목록을 유지하며 변경되지 않은 행은 그대로 표시
용량 미확인 값을 0 또는 충분으로 표시하지 않음
